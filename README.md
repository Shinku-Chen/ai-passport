# 9-nine- 春色春恋春熙风 · AI Passport 离线阅读器

把 AI Passport（ESP32-C3、8 MB Flash、无 PSRAM、320×240 横屏、三键）变成
《9-nine- 春色春恋春熙风 / 9 -Nine-: Episode 3》的**完整离线视觉小说阅读器**。
不联网、不读外部文件：剧情、画面、BGM 与 OP 全部编译进一个整机镜像。

- 分支：`release/nine-haruiro-20261125`（本 README 只介绍这一部作品）
- 框架：`feature/galgame-framework` 基线 `b9909c13`，保留其页面、三键、分页与持久化交互
- 来源：`xuanyide01/9-nine-rw5` @ `6a8907a5ae576f4377abe4b74f15bd9af13efe07`
- 详细设计、预算与验证：[`docs/development/engineering/nine-haruiro-port.zh_CN.md`](docs/development/engineering/nine-haruiro-port.zh_CN.md)

固定来源是 REDMI Watch 5 的**非 R18 中文主线**加工版，本移植以它为唯一权威：

| 项 | 数量 |
| --- | --- |
| 剧情节点 / 章节 | 78 / 15 |
| 正文帧 | 10,659（另有 1 条 OP 标记） |
| 选项 / 可见选项 | 13 / 13 |

| 状态变量 | 23（10 个永久键） |

来源快照本身排除了 11 个 R18 场景与全部语音；本移植不重建、不臆造这部分内容。
"完整"指相对该固定快照的完整：每一句正文、每一个选项目标、两条结局与全部画面引用都在包内。
10,659 句正文与来源逐句对账，10,674 步轨迹与来源 `engine.js` 完全一致。

## 玩法与操作

320×240 横屏。完整 320×180 画面占上方；说话人名字是贴合文字的紧凑半透明铭牌，叠在画面上、位于正文框上方；正文框占底部 60 px，16 px 字三行 / 20 px 字两行。阅读页不显示页码数字；章节名在左上、电量在右上。

| 操作 | 行为 |
| --- | --- |
| 短按 OK / 上 / 下 | 立即推进：打字中的页先补全，同一次按键继续翻到下一页/下一句；不会只补字而不推进 |
| **长按 OK** | 打开游戏内菜单（返回剧情、存档、读档、历史、设置、返回标题） |
| **长按下** | 切换自动阅读；整页打完后等 1.2 秒进入下一句 |
| **按住上** | 快进：长按阈值到达立即进入下一句，跳过本句剩余分页与打字/自动等待；持续按住每个输入 tick 至多一整句，无额外 90/120 ms 累积；松开即停、不补短按；选项/结局/OP/资源错误停住 |
| 选项页 | 上/下选择，OK 确认；长按 OK 与阅读页一样打开游戏内菜单，返回后原选项与选择位置不变 |
| 二级页面 | 上/下移动或切换，长按 OK 返回 |

- 自动阅读中短按任意键：关闭自动，**并且照常推进一句**。
- 短按一定推进页/句游标，不会出现“第一下只补全、第二下才推进”。
- 长按释放不会补发一次短按；进入/退出菜单、自动、快进时都会清理对应状态。
- 菜单动作不移动剧情游标；阅读页与选项页进入菜单后，返回会恢复原正文分页或完整选项与选择位置。
- 手动存档 **30 槽**（4 行滑动窗口）＋自动进度。周目变量、手动/自动存档、永久结局资格
  三者独立：读旧档会恢复当时的位置、正文分页与周目变量，但不会回退后来解锁的结局与主视觉；
  超出当前帧页数的旧分页会夹到最后一页。
- 鉴赏室：CG 18 组/100 张差分（上/下切差分）、15 章试读、2 首 BGM、OP 鉴赏。OP 鉴赏播放完整片头动画与片头曲；自然结束、短按 OK 跳过、长按 OK 返回都会回到同一 OP 行，不推进剧情。章节试读不写永久进度。
- 标题主视觉 1/2/3 按来源 UI 的永久 loop/true 资格解锁（不是 transient `titleBg`）：
  任一中盘/真结局资格解锁第 2 张，两者都有解锁第 3 张；二周目到 n40 不会退锁。
- 存档带 CRC 与作品身份；坏档只提示"校验失败"，绝不覆盖当前 live 状态。

## 构建与烧录

需要 ESP-IDF 5.5.3：

```bash
./tools/validate.sh --static      # 仓库检查 + 全部 host 测试（含源轨迹差分）
./tools/validate.sh --firmware    # 全新构建 + 合并镜像 + verify_firmware + 归档
idf.py -p <port> flash monitor    # 需要真机时自行执行
```

产物：`build/FoloToy-AI-Passport-full.bin`（整机镜像，从 0x0 烧录）与
`build/firmware/<sha>/`（app/full/ELF/MAP 归档）。本分支不提交 tag、不发布 Release、
不改动其它作品的分支或标签。

## 资源与预算（最终固件）

| 项 | 字节 |
| --- | ---: |
| 剧情包 | 778,099 |
| 图像/音频包 | 4,969,689 |
| 编译后 16/20 px 中文字库 | 799,119 |
| 应用镜像 | 8,062,448 / 8,323,072（96.9%，余 260,624） |
| 合并整机镜像 | 8,127,984 |
| 静态 DRAM | 160,744 / 321,296（50.0%） |

- 画面：来源 432×243 → 包内 320×180（保留完整构图/立绘锚点/表情差分）→ 运行期
  256×144 画布（6 条 12,288 B 条带）→ 面板放大 1.25× 到 320×180。256 画布是 C3
  堆预算下的真实取舍，已在设计文档中量化。
- BGM：16 kHz 单声道 IMA ADPCM（1,518,396 B）。来源 36 kbps Opus 已完整解码重采样。
- OP：完整 493 帧 @5 fps（98.62 秒），与片头曲同步播放；来源无语音可保留。
- 最大单次内存分配 12,288 B；没有任何 >32 KB 的连续分配。LVGL 使用系统堆，
  不再预留 64 KB 私有池。
