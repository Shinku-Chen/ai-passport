# GalGame 框架开发手册

本手册说明 `feature/galgame-framework` 分支上的通用 GalGame 框架：它能做什么、
代码怎么分层、如何接入一部新作品、以及怎么验证和排错。

框架本身**不包含任何具体作品内容**；仓库里的骨架固件自带一组占位内容
（对白、选项、章节、CG、曲目），用来跑通全部页面与机制。接入作品时只替换
内容层，界面与交互保持不变。

设计原型见 [galgame-ui-wireframes/prototype.html](../../design/galgame-ui-wireframes/prototype.html)：
19 个逻辑屏、每屏同时给出 240×320 竖屏与 320×240 横屏示意。

## 1. 框架能力

| 能力 | 说明 |
| --- | --- |
| 19 个逻辑屏 | 启动、标题、对话、选项、游戏内菜单、存档、读档、设置、历史文本、鉴赏室、CG 鉴赏、CG 回想、剧情鉴赏（章节 / 路线）、音乐鉴赏、确认弹窗、章节过场、结局、关于、CG 全屏浏览 |
| 分页排版 | 长句按“每行字数 × 每页行数”自动分页，行首禁则标点挂在本行行尾；字号 16 / 20px 两档 |
| 阅读操作 | 打字机、按住快进（松开停）、自动阅读（章节过场会自动过去，不打断自动） |
| 剧情锁 | CG / 章节 / 结局解锁位 + 剧情标记；支持条件台词、条件选项、条件章节 |
| 持久化 | 设置、3 个手动存档槽、自动阅读进度、剧情锁四类分别存 NVS |
| 鉴赏室 | CG 鉴赏（未解锁显示问号）、CG 回想（重演已看过的场景）、剧情鉴赏、音乐鉴赏 |
| 音频 | 骨架用方波合成占位旋律（16kHz / 16bit / 单声道），播放跑在独立任务里 |
| 界面 | 240×320 竖屏；背景、CG 缩略图、CG 全屏图都是程序绘制，不携带美术资源 |

## 2. 目录

```
main/main.c              启动、输入任务、空闲策略（调暗 / 熄屏 / 深睡）、唤醒按键守卫
main/gal/
  gal_content.[ch]       内容层：对白、事件流、选项、章节、CG、回想、曲目、菜单、关于
  gal_app.[ch]           状态机：页面导航、按键语义、进度与解锁结算、历史记录
  gal_ui.[ch]            LVGL 界面层：19 个页面、列表组件、打字机
  gal_text.[ch]          分页排版（纯逻辑，可宿主机测试）
  gal_tone.[ch]          方波合成（纯逻辑，可宿主机测试）
  gal_music.[ch]         音乐播放任务 + I2S / ES8311 通路
  gal_settings.[ch]      展示设置（NVS）
  gal_save.[ch]          3 个手动存档槽（NVS）
  gal_progress.[ch]      自动阅读进度（NVS）
  gal_unlock.[ch]        剧情锁：解锁位与剧情标记（NVS）
assets/fonts/             gal_cjk_16.c / gal_cjk_20.c / gal_cjk_symbols.txt（工具生成，入库）
tools/gal_font.py         中文字体子集生成 + 覆盖自检
tests/                    宿主机测试（排版、方波、BSP 相关）
docs/design/galgame-ui-wireframes/prototype.html   19 屏原型（竖屏 + 横屏）
```

## 3. 快速上手

### 构建与烧录

使用 ESP-IDF 5.5.3（环境准备见 [environment-setup.zh_CN.md](environment-setup.zh_CN.md)）：

```bash
source <ESP-IDF-v5.5.3-路径>/export.sh
idf.py build                      # 增量编译
idf.py -p <串口> flash            # 烧录 app
idf.py -p <串口> monitor          # 看日志
```

### 门禁

```bash
./tools/validate.sh --static      # 仓库检查 + 宿主机测试（含分页与方波测试）
./tools/validate.sh --firmware    # ESP-IDF 构建 + 合并镜像校验
./tools/validate.sh               # 全量（需要已激活 ESP-IDF 5.5.3）
```

macOS 上跑宿主机测试需要 `CC` 指向能处理 `--gc-sections` 的编译器包装，
见 [build-and-test.zh_CN.md](build-and-test.zh_CN.md)。

### 字体

内容改动后必须重新生成字体子集（`validate.sh` 会检查覆盖情况）：

```bash
python3 tools/gal_font.py --font <源字体>.otf --out-dir assets/fonts
python3 tools/gal_font.py --check --out-dir assets/fonts   # 只检查
```

字符集来自 `main/` 下源文件的字符串字面量，所以新增文案后重跑即可。
源字体本身不入库（OFL 字体按需自行下载）。

## 4. 按键规范（三键：↑ / ↓ / OK）

| 页面 | 短按 | 长按 |
| --- | --- | --- |
| 启动页 | OK 进入标题页 | — |
| 标题页 | ↑/↓ 移动菜单，OK 进入 | — |
| 对话页 | OK / ↑ / ↓ 都是「下一句」（打字中先整页显示） | OK = 游戏内菜单；↑ = 快进（松开停）；↓ = 自动阅读开关 |
| 选项页 | ↑/↓ 选择，OK 确认（条件不足会提示） | OK 返回对话 |
| 游戏内菜单 | ↑/↓ 选择，OK 执行 | OK 返回剧情 |
| 存档 / 读档页 | ↑/↓ 选槽，OK 保存 / 读取 | OK 返回上一级 |
| 设置页 | ↑/↓ 选择，OK 切换值 | OK 返回上一级 |
| 历史文本 | ↑/↓ 滚动 | OK 返回 |
| 鉴赏室 | ↑/↓ 选分类，OK 进入 | OK 回标题页 |
| CG 鉴赏 | ↑/↓ 选缩略图，OK 全屏浏览 | OK 回鉴赏室 |
| CG 回想 | ↑/↓ 选场景，OK 重演那一段 | OK 回鉴赏室 |
| 音乐鉴赏 | ↑/↓ 选曲目，OK 播放 / 停止 | OK 回鉴赏室（并停播） |
| 剧情鉴赏 | ↑/↓ 选章节，OK 从该章节开始 | OK 回鉴赏室 |
| 章节过场 | 任意短按继续（自动阅读时自动过去） | — |
| 结局 | OK 回标题页 | OK 回标题页 |
| 关于 | ↑/↓ 滚动（长按滚动更快） | OK 返回标题页 |
| CG 全屏浏览 | ↑/↓ 切换，OK 回缩略图页 | — |
| 覆盖确认弹窗 | ↑/↓ 选按钮，OK 执行 | OK 取消 |

自动阅读开启后，**按任意键都会先退出自动阅读**（这次按键被吃掉，不触发其它动作）。

## 5. 排版规范

| 方向 | 分辨率 | 对话框面板 | 16px 档 | 20px 档 |
| --- | --- | --- | --- | --- |
| 竖屏（骨架固件） | 240×320 | 贴底 110px | 每行 13 字、每页 5 行 | 每行 10 字、每页 4 行 |
| 横屏（BSP 提供 API） | 320×240 | 贴底 90px | 每行 19 字、每页 4 行 | 每行 15 字、每页 3 行 |

- 屏内所有文字统一使用对话字号档位（16 / 20px），不设 10–12px 小字。
- 名牌挂在对话框上沿**外侧**、左对齐；旁白不显示名牌。
- 「自动」指示挂在对话框上沿外侧右上角，只有文字没有边框底纹。
- 对话底纹透明度 10%–55%（步进 5%，默认 30%），可在设置里调整。
- 行距为 字体行高 + 1px（16px 档 20px、20px 档 24px），对齐上述“每页行数”。

## 6. 页面与导航

```
启动页 ──OK──▶ 标题页
标题页 ─┬─ 开始新游戏 ─▶ 对话页（清空进度，从第一句开始）
        ├─ 继续游戏   ─▶ 对话页（从自动进度接上，无进度时置灰）
        ├─ 读取存档   ─▶ 读档页（无存档时置灰）
        ├─ 设置       ─▶ 设置页（标题页打开 6 项）
        └─ 鉴赏室     ─▶ 鉴赏室
鉴赏室 ─┬─ CG 鉴赏   ─▶ CG 缩略图 ──OK──▶ CG 全屏浏览
        ├─ CG 回想   ─▶ 已看过的场景列表 ──OK──▶ 重演那一段（回到对话页）
        ├─ 剧情鉴赏 ─▶ 章节列表 ──OK──▶ 从该章节开始
        └─ 音乐鉴赏 ─▶ 曲目列表 ──OK──▶ 播放 / 停止
对话页 ──长按 OK──▶ 游戏内菜单 ─┬─ 返回剧情
                                ├─ 保存进度 ─▶ 存档页（覆盖前弹确认）
                                ├─ 读取进度 ─▶ 读档页
                                ├─ 历史文本
                                ├─ 设置（阅读中打开 7 项，多一个「返回标题」）
                                └─ 返回标题
剧情推进 ─▶ 选项（条件不满足会置灰）─▶ 章节过场 ─▶ … ─▶ 结局 ──OK──▶ 标题页
```

## 7. 接入一部新作品

### 7.1 替换内容层

只需要改 `main/gal/gal_content.c`（声明在 `gal_content.h`）：

| 数组 / 宏 | 内容 |
| --- | --- |
| `gal_content_lines[]` | 对白：说话人（空串 = 旁白）、正文、条件标记 |
| `gal_content_events[]` | 事件流：`{类型, 下标, 到达时写入的标记}`，类型为对白 / 选项 / 过场 / 结局 |
| `gal_content_choices[]` | 选项组：提示句 + 选项数组（每个选项可写标记、可要求标记） |
| `gal_content_transitions[]` | 章节过场：归属章节、小标、标题、副标题 |
| `gal_content_endings[]` | 结局：小标、标题、正文 |
| `gal_content_cgs[]` | CG：编号、名称、解锁事件 |
| `gal_content_chapters[]` | 章节：名称、简介、完成度文本、解锁事件、所需标记 |
| `gal_content_recalls[]` | CG 回想：场景名、所在章节、所需 CG、重演起点事件 |
| `gal_content_tracks[]` | 音乐：曲名、时长文本、所需 CG、音符序列 |
| `gal_content_*_menu[]` | 标题页菜单与游戏内菜单的文字 |
| `gal_content_about_rows[]`、`GAL_CONTENT_ABOUT` 等 | 关于页信息 |

`GAL_CONTENT_TITLE` / `SUBTITLE` / `LOGO_SUB` / `VERSION` 替换成作品信息。

### 7.2 剧情锁

三类解锁状态存在 `gal_unlock`（位掩码，最多 32 个）：

- 台词：`require_flag` 不满足时该事件**自动跳过**（这就是条件分支）。
- 选项：`require_flag` 不满足时置灰，按确定提示「条件不足」；`flag_set` 在选中后写入。
- CG / 章节：到达 `unlock_event` 时解锁；章节还可要求 `require_flag`。
- 事件本身可携带 `flag_set`（例如章节过场写「已到第二章」、结局写「已通关」）。
- 标记枚举写在 `gal_content.h` 的 `GAL_FLAG_*`，作品自行增删。

解锁记录跨存档长期保存，存档槽只记位置，不复制解锁状态。

### 7.3 字体

新增文案后重跑字体生成（见 §3），`--check` 已在 `validate.sh` 里，缺字会让门禁失败。

### 7.4 美术与音频

- 背景、CG 缩略图与 CG 全屏图目前是程序绘制的渐变（`gal_ui.c`），换成
  `lv_image` + 图片资源即可；列表行、按钮、对话框面板的样式不用改。
- 音乐鉴赏当前用 `gal_tone` 合成方波（`gal_music` 负责任务与 I2S）。接真实音频时
  替换 `gal_music.c` 里的播放循环：解码后的 PCM 同样走 `bsp_audio_write()`，
  采样格式用 `bsp_audio_set_format()` 设置。
- 若作品带横屏素材，用 BSP 的横屏接口并提供 320×240 的裁切资源。

## 8. 持久化一览

| NVS 命名空间 | key | 内容 | 写入时机 |
| --- | --- | --- | --- |
| `galcfg` | `cfg` | 文字速度、字号档、自动阅读、对话透明度 | 设置项改变时 |
| `galsave` | `slots` | 3 个手动存档槽（事件 + 页 + 章节名） | 存档页手动保存时 |
| `galprog` | `pos` | 自动阅读进度（事件 + 页） | 推进剧情后节流写（≤2 秒一次），深睡前强制落盘 |
| `galunlock` | `bits` | CG / 章节 / 结局解锁位 + 剧情标记 | 有变化时（到达解锁事件 / 选项写入标记） |

进度节流是为了控制 NVS 擦写次数；`gal_app_flush()` 用于关键节点（深睡）强制落盘。

## 9. 测试

| 测试 | 覆盖 |
| --- | --- |
| `tests/test_gal_text.c` | 分页：整行装填、按页切分、偏移、显式换行、边界 |
| `tests/test_gal_tone.c` | 方波：周期与占空比、静音、块首斜坡、非法参数 |
| `tests/test_key_guard.c` 等 | 唤醒按键守卫、BSP 故障注入与休眠恢复 |

新增纯逻辑（状态机、排版、时序）时，把它做成不依赖 ESP-IDF / LVGL 的模块并补宿主测试，
再接入 `tools/validate.sh`。

## 10. 常见问题

- **屏幕上出现方块 / 乱码**：字体子集缺字。跑 `tools/gal_font.py --check`，缺字时重新生成。
  另注意列表行是按需创建的，字号切换必须同时更新已存在的行（`gal_ui_set_font_size` 已处理）。
- **改了文案但界面没变**：需要重新生成字体并重新构建；`--check` 会在门禁里挡住这种情况。
- **设备突然从电脑上消失**：空闲 420 秒会进 deep sleep，USB 随之断电，按任意键唤醒即可（唤醒后重启）。
- **音乐没声音**：确认 ES8311 与 I2S 通路（`bsp_audio_*`）；播放失败会在串口打印日志。
- **NVS 相关**：解锁与进度都只在“有变化”时写；不要把高频状态直接写 NVS。
- **并发**：LVGL 不是线程安全的，任何非 LVGL 任务改界面都要持 `bsp_lvgl_lock()`；
  按键回调必须非阻塞（慢操作放任务，例如音乐播放）。

## 11. 验证与交付

交付固件改动时按仓库要求分别报告：

```text
Build:      PASS / FAIL / NOT RUN
Host tests: PASS / FAIL / NOT RUN
Device tests: PASS / FAIL / NOT RUN
Unverified: 剩余的板级 / 仪器 / 人工检查
```

烧录前无需备份设备原有固件，但也不会保留用户数据；需要保留时先导出。
