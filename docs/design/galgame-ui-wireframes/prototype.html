页面原型与屏幕布局

17 个页面/状态 · 每页提供 240×320 竖屏与 320×240 横屏示意

方向在编写时配置
修改源码中的 PREVIEW_ORIENTATION 为 "portrait"、"landscape" 或 "both"。页面内没有方向切换选项。
分辨率基准：每张屏按设备物理分辨率 1:1 绘制（竖屏 240 × 320、横屏 320 × 240；1 CSS 像素 = 1 设备像素；ST7789P3 / RGB565）。原型字号即设备字形档位：对白 16/20px 两档（竖屏排版取 Asunabi、横屏取沙耶参考版）、辅助与提示 10px、标题 20px 起，真机上不建议使用低于 10px 的字形。素材按各方向整屏尺寸产出，不做运行时缩放。原型中点击选项可查看对应状态；设备用 ↑、↓、OK 三个实体键操作，聚焦对话页或存档页后可用键盘模拟。
