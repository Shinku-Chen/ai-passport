# v1.0.0-nine-haruiro 发布说明

## 本次新增

《9-nine- 春色春恋春熙风》完整离线剧情现已可在 AI Passport 上阅读：15 章、
13 个选项、两个结局里程碑、18 组共 100 张 CG 差分、15 章试读、2 首音乐，
以及 OP 鉴赏。

- OP 鉴赏播放完整片头动画与片头曲。自然结束、短按 OK 跳过、长按 OK 返回都会
  回到同一 OP 行，不改变剧情。
- 阅读画面使用完整 320×180 美术、紧凑贴合的半透明说话人铭牌，以及底部正文框
  （16 px 三行或 20 px 两行）。阅读页不再显示页码数字；真实分页与存档页位置
  仍然有效。
- 快进每个输入 tick 推进整句，松开即停。LVGL 短暂占用时按键会保留重试，不再
  丢动作。
- 鉴赏普通浏览按设计静音；片头与显式选择的音乐正常连续。返回标题会恢复标题
  音乐。

## 使用方法

将合并整机镜像烧录到地址 `0x0` 后启动。三个实体按键提供短按与长按操作：

- 短按 OK / 上 / 下推进阅读；打字中短按会先补全本页，并在同一次按键继续推进。
- 阅读与选项页长按 OK 打开游戏内菜单，包含返回剧情、存档、读档、历史、设置与
  返回标题。
- 长按下切换自动阅读；按住上快进，松开即停且不补短按。
- 标题菜单进入鉴赏室，可选择 CG、章节试读、音乐或 OP；二级页面长按 OK 返回。
- 存档/读档提供 30 个手动槽位与自动进度；损坏槽位会提示，不会覆盖当前位置。
