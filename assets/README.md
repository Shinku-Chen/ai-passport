# Assets

This directory stores reusable fonts, images, music, and sound effects, organized by asset type.

Keep each asset in the matching subdirectory and document its destination, naming, integration method, and source/license. Do not mix binary assets with Markdown documentation.

## Fonts

Store reusable font files and generated font sources in `fonts/`.

- Use descriptive names that include the family, weight, size, and format when relevant.
- Document the source, license, character range, conversion command, and expected destination.
- Check Flash and internal-RAM impact before adding a font; the ESP32-C3 has no PSRAM.
- Do not commit fonts whose license does not permit redistribution.

| [`images/logo-wordmark.png`](images/logo-wordmark.png) | 1648 × 336, PNG RGBA | Transparent black wordmark extracted from the repository's original `images/logo.png`; embedded in both project README files for light backgrounds. |
| [`images/logo-wordmark-dark.png`](images/logo-wordmark-dark.png) | 1648 × 336, PNG RGBA | White version of the extracted wordmark, used by the README `<picture>` element when GitHub is in dark mode. |

- Use descriptive names and document dimensions, pixel format, conversion steps, and destination.
- Prefer formats suitable for the 240 × 320 RGB565 display and account for Flash and internal RAM.
- Preserve editable sources where licensing permits, and record the source and license.
- Never commit device QR secrets, credentials, or personal data in images.

## Third-party source material (`sanoba-source/`)

The Sanoba Witch port (branch `feature/sanoba-witch`) ships the upstream material it
packs, plus the rest of the game material, so a plain checkout can rebuild the packs
offline and still describe what they were built from:

| Path | Content | Source and licence |
| --- | --- | --- |
| `sanoba-source/bg/` | 107 backgrounds, 336 × 480 JPEG | Yuzusoft, via the Mi Band port [`hrk666666/Sanoba-Witch-MiBand-10`](https://github.com/hrk666666/Sanoba-Witch-MiBand-10) (itself based on the archived `futrw4v/Sanoba-Witch-MiBand-9Pro`) |
| `sanoba-source/sd/` | 292 SD (super-deformed) event images, 240 × 144 JPEG | same |
| `sanoba-source/scn/` | 101 chapter scripts, node-array JSON converted from the original KiriKiri `.ks` files | same; the Simplified-Chinese text is the work of its fan-translation group |
| `sanoba-source/images/` | 29 project icons and decorative PNGs — game material the reader does not use | same |
| `sanoba-source/title_bg.jpg` | title key visual, 336 × 480 JPEG | same |
| `sanoba-source/logo.png` | project logo — game material the reader does not use | same |
| `sanoba-source/game.txt` | content-package manifest: scenario order and the 019 route rule | same |
| `sanoba-source/upstream-screenshots/` | the four screenshots used by the upstream README, kept for reference | same |
| `sanoba-source/script-format-spec-v1.1.txt` | the upstream script-format specification that these packers implement (upstream keeps it under a Chinese file name) | same |
| `sanoba-source/LICENSE` | the upstream GPL-3.0 licence text covering its material and documentation | upstream repository |
| `sanoba-source/MANIFEST.json` | per-file upstream path, byte size and sha256 of the fetched revision | generated by [`tools/sanoba_fetch_source.py`](../tools/sanoba_fetch_source.py) |

- The upstream quick-app code (`src/**/*.ux`, `src/**/*.js`, `src/engine/`, `tests/`,
  `tools/`) is deliberately **not** mirrored here — only the game's own material is.
- **Upstream status (checked 2026-10-03).** The upstream repository's history was
  rewritten on 2026-09-26: its `main` now hosts another port (Senren \* Banka, with its
  own `ch/` and `ev/` art) and the Sanoba Witch material is gone from it. What remains
  upstream is the `band9-10-sync` branch (v1.2.1, 2026-09-18), whose backgrounds, SD
  images and scripts are byte-for-byte identical to this archive but which has no
  `game.txt`, no `images/` and no `logo.png`. This directory is therefore the
  authoritative copy: a plain checkout rebuilds both packs, and
  `tools/sanoba_fetch_source.py` defaults to that branch and leaves those three inputs
  to the archive. The 141 standing images and 570 event CGs now on `main` belong to that
  other title, not to Sanoba Witch.
- Provenance, hashes, and the upstream commit come from `MANIFEST.json`; refresh the copy
  with `python tools/sanoba_fetch_source.py --dest assets/sanoba-source --chunks`.
- Rebuild the packs straight from here:
  `python tools/sanoba_scn_pack.py --source assets/sanoba-source --out main/sanoba_data/sanoba_scn.bin`
  and `python tools/sanoba_pack.py --source assets/sanoba-source --out main/sanoba_data/sanoba_pack.bin`.
- Copyright belongs to Yuzusoft (art) and to the fan-translation group (text). The material is kept
  for personal study and technical demonstration only; do not use it commercially, and support
  the official release.

## Music and sound effects

Store reusable music and sound-effect sources in `music/`.

- Document the source, license, sample rate, bit depth, channels, conversion command, and destination.
- Prefer 16 kHz, 16-bit mono PCM when it matches the current BSP audio path.
- Check Flash and internal-RAM cost before embedding audio; stream or chunk long recordings.
- Do not commit media without redistribution permission.
